# Measuring Partisan Gerrymandering Across U.S. States

## Overview

A statistical and geospatial analysis of congressional districts across California, Georgia, Michigan, Ohio, and Texas. This project examines partisan electoral imbalance using historical election data and multiple quantitative measures.

## Research Objectives

- Quantify partisan electoral imbalance across five states.
- Evaluate congressional district competitiveness and geographic compactness.
- Compare statewide vote shares with district-level electoral outcomes.
- Investigate the relationship between voter distribution and political representation.

## Analytical Methods

- Efficiency gap
- Seat bonus
- District competitiveness
- Polsby-Popper compactness
- Declination
- Electoral swing analysis
- Geospatial analysis

## Technologies Used

- **Language:** R
- **Data Manipulation:** tidyverse, dplyr
- **Visualization:** ggplot2, scales
- **Geospatial Analysis:** sf, lwgeom
- **Reporting:** R Markdown, knitr

## Data Source

ALARM Project — Harvard Dataverse

The analysis uses precinct-level election results from 2016 and 2020, demographic information, and congressional district boundaries.

## Project Files

- Research report — methodology, visualizations, results, and conclusions.
- R analysis — data processing, statistical calculations, and visualization code.

## Limitations

- Presidential election results are used as a proxy for congressional voting behavior.
- Geographic voter concentration can influence measures of partisan imbalance.
- Statistical measures alone cannot establish intentional gerrymandering.

## Project Background

Originally developed as a research project for Political Science Research Methods (PLS 300) at Grand Valley State University in Spring 2025.
